# Portfolio CV - Nguyễn Thế Đạt

## 1. Sản phẩm 

Portfolio CV của Nguyễn Thế Đạt, sinh viên ngành công nghệ thông tin trường đại học Đại Nam

Website giới thiệu thông tin cá nhân, kỹ năng lập trình, dự án, thông tin liên hệ

Sản phẩm được xây dựng bằng HTML5 và CSS3.

## 3. Tính năng

- Giới thiệu thông tin cá nhân, sở thích
- Trình bày kỹ năng C++, HTML5, CSS3 và sử dụng visual studio code
- Hiện thị dự án với hình ảnh minh họa
- Cung cấp email cá nhân và link github
- Form liên hệ và kết quả dữ liệu HTML5
- Bố cục responsive hỗ trợ kích thước màn hình khác nhau 

## 4. Công nghệ sử dụng 
- HTML5: xây dựng cấu trúc và nội dung website
- CSS3: thiết kế giao diện
- Google Fonts - Inter: hiển thị kiểu chữ
- Github Pages: xuẩn bản website
